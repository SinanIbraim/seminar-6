# Simulation Logs (`log/`)

This directory will contain log files (`.csv`) with the full results of simulations performed by scripts from the `../scripts/` directory of Seminar 7 (Backstepping) (i.e., `seminars/seminar_7_backstepping/scripts/`).

## File Naming

The name of each log file will correspond to the seminar part name (e.g., `4_1_pendulum_backstepping_sim`) with the prefix `log_` and the extension `.csv`.

**Example:** The script `../scripts/script_4_1_pendulum_backstepping_sim.py` will generate the log `log_4_1_pendulum_backstepping_sim.csv` in this directory.

**Important:** File names are **fixed** for each seminar part. Rerunning the corresponding script will **overwrite** the log file without warning.

## CSV Format

Files are typically generated by the `Simulator` class (from `../src/simulator.py`), which internally manages logging of system states, control inputs, etc.
*   **First line:** Column headers (`time`, `variable_name_1`, `variable_name_2`, ...).
*   **Subsequent lines:** Numerical values at the corresponding time points.
*   **Delimiter:** Comma (`,`).
