# Simulation Result Plots (`img/`)

This directory will contain image files (`.png`) with plots of simulation results from scripts in the `../scripts/` directory of Seminar 7 (Backstepping) (i.e., `seminars/seminar_7_backstepping/scripts/`).

The plots will be generated by the `Plotter` class from `../src/plotter.py`.

## File Naming

The name of each image file will correspond to the seminar part name (e.g., `4_1_pendulum_backstepping_sim`) with the prefix `img_` and the extension `.png`.

**Example:** The script `../scripts/script_4_1_pendulum_backstepping_sim.py` will generate the plot `img_4_1_pendulum_backstepping_sim.png` in this directory.

**Important:** File names are **fixed** for each seminar part. Rerunning the corresponding script will **overwrite** the image file without warning.
